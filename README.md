## 1. Présentation du Projet

### 1.1 Contexte

Dans le cadre du module **Architecture Logicielle**, ce projet consiste
à concevoir et développer une **plateforme complète de gestion
d'événements en ligne**.

### 1.2 Description Générale

La plateforme facilite l'organisation d'événements de toutes sortes :
conférences, concerts, formations, séminaires, événements sportifs...

### 1.3 Objectifs Pédagogiques

-   Architecture Microservices\
-   Architecture Event-Driven\
-   Patterns de conception modernes\
-   Modélisation UML complète
